    Size is not structure

    Making text big and bold changes how it looks. It does not tell anything that reads the page what the text is. A heading is a tag, not a font size, and the heading tool in the Canvas editor is the only thing that sets it.

    The second rule is do not skip levels. Going from Heading 2 straight to Heading 4 tells a screen reader there is a missing section between them, so the outline it builds is wrong even though every heading on the page is real.

    In Canvas the page title is already the page's Heading 1, so your first heading inside the page body is a Heading 2. A second H1 in the body is a duplicate.
