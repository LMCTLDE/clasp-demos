CLASP Accessibility Demos

Interactive demos from TLDE's CLASP sessions at Lake Michigan College: Captions, Links, Alt text, Structure, Palette. Each page shows the same thing twice, before and after. The read-aloud buttons use your browser's built-in voice, so turn your sound on.

  • CLASP

    The one-stop page. All five letters plus tables, each with a before and after you can play.

  • Caption Check

    A lecture clip with sound off, played with machine captions and then edited ones.

  • Link List Demo

    What a page's links sound like to a screen reader, plus a colour contrast checker.

  • Alt Text Read Aloud

    One page with three images, read aloud with Canvas file names and then with real alt text.

  • Heading List Demo

    The heading list a screen reader builds from bold text versus real headings.
